# ALLCLL UI

ALLCLL 서비스에 사용하는 디자인 시스템입니다. 화면에서 반복되는 요소는 이곳의 컴포넌트를 먼저 찾아 사용하고, 없으면 이곳에 추가해 서비스 전반이 같은 모양을 유지하도록 합니다.

```tsx
import { Button, Pagination, CheckmarkIcon } from '@allcll/allcll-ui';
```

- 스타일은 Tailwind CSS 4를 사용합니다. 색상은 패키지 루트의 `theme.css`, `colors.ts`에서, z-index는 `zIndex.ts`에서 관리합니다.
- 아이콘은 lucide-react를 서비스에 맞는 이름으로 다시 내보내어 사용합니다(`src/icons`).

## 색상 토큰

### 역할별 색상

배경, 텍스트, 테두리 색은 `theme.css`에 쓰임새별로 정의되어 있습니다. 같은 이름이 다크 모드에서는 어두운 테마에 맞는 색으로 바뀌므로, `bg-white`, `text-gray-500`처럼 색을 직접 고르는 Tailwind 기본 클래스 대신 `bg-surface`, `text-fg-muted`, `border-line`처럼 사용합니다.

<RoleColorPalette />

### 팔레트

`primary`, `danger`는 `colors.ts`에서 정의한 커스텀 색상이고, 이외의 색상은 Tailwind 기본 팔레트를 사용합니다. 팔레트 색은 다크 모드에서도 같은 값을 사용합니다.

<ColorPalette>
  <ColorItem title="primary" subtitle="주요 동작, 선택 상태" colors={shades(colors.primary)} />
  <ColorItem title="danger" subtitle="오류, 삭제" colors={colors.danger} />
</ColorPalette>

## z-index 단계

겹침 순서는 `zIndex.ts`의 단계로만 정합니다. Tailwind 클래스는 `z-content`, `z-modal`처럼 쓰고, `z-[123]` 같은 임의 값은 사용하지 않습니다. 새 단계가 필요하면 `zIndex.ts`에 먼저 추가합니다.

<table>
  <thead>
    <tr>
      <th>단계</th>
      <th>값</th>
      <th>용도</th>
    </tr>
  </thead>
  <tbody>
    {Object.entries(Z_INDEX).map(([layer, value]) => (
      <tr key={layer}>
        <td>
          <code>{layer}</code>
        </td>
        <td>{value}</td>
        <td>{Z_INDEX_USAGE[layer]}</td>
      </tr>
    ))}
  </tbody>
</table>
