# ALLCLL UI

ALLCLL 서비스에 사용하는 디자인 시스템입니다. 화면에서 반복되는 요소는 이곳의 컴포넌트를 먼저 찾아 사용하고, 없으면 이곳에 추가해 서비스 전반이 같은 모양을 유지하도록 합니다.

```tsx
import { Button, Pagination, CheckmarkIcon } from '@allcll/allcll-ui';
```

- 스타일은 Tailwind CSS 4를 사용하고, 색상과 z-index는 패키지 루트의 `colors.ts`, `zIndex.ts`에서 관리합니다.
- 아이콘은 lucide-react를 서비스에 맞는 이름으로 다시 내보내어 사용합니다(`src/icons`).

## 색상 토큰

`primary`, `danger`, `text`는 `colors.ts`에서 정의한 ALLCLL 색상이고, 이외의 색상은 Tailwind 기본 팔레트를 사용합니다.

<ColorPalette>
  <ColorItem title="primary" subtitle="주요 동작, 선택 상태" colors={shades(colors.primary)} />
  <ColorItem title="danger" subtitle="오류, 삭제" colors={colors.danger} />
  <ColorItem title="gray" subtitle="본문, 테두리, 배경 (Tailwind 기본)" colors={TAILWIND_GRAY} />

</ColorPalette>

## z-index 단계

겹침 순서는 `zIndex.ts`의 단계로만 정합니다. Tailwind 클래스는 `z-content`, `z-modal`처럼 쓰고, `z-[123]` 같은 임의 값은 사용하지 않습니다. 새 단계가 필요하면 `zIndex.ts`에 먼저 추가합니다.

<table>
  <thead>
    <tr>
      <th>단계</th>
      <th>값</th>
      <th>용도</th>
    </tr>
  </thead>
  <tbody>
    {Object.entries(Z_INDEX).map(([layer, value]) => (
      <tr key={layer}>
        <td>
          <code>{layer}</code>
        </td>
        <td>{value}</td>
        <td>{Z_INDEX_USAGE[layer]}</td>
      </tr>
    ))}
  </tbody>
</table>

## 컴포넌트

이름을 누르면 문서로 이동합니다. 회색 이름은 아직 문서가 없는 컴포넌트입니다.

<div style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fill, minmax(260px, 1fr))', gap: 16 }}>
  {CATEGORIES.map(category => (
    <section
      key={category.name}
      style={{ border: '1px solid #e5e7eb', borderRadius: 8, padding: '12px 16px' }}
    >
      <h3 style={{ margin: '0 0 8px', fontSize: 14 }}>{category.name}</h3>
      <ul style={{ margin: 0, paddingLeft: 0, listStyle: 'none' }}>
        {category.items.map(([name, description, hasDocs = true]) => (
          <li key={name} style={{ margin: '6px 0', fontSize: 13, lineHeight: 1.5 }}>
            {hasDocs ? (
              <a href={docsHref(category.name, name)} target="_top" style={{ fontSize: 13 }}>
                {name}
              </a>
            ) : (
              <span style={{ color: '#9ca3af', fontSize: 13 }}>{name}</span>
            )}
            <span style={{ color: '#6b7280', fontSize: 13 }}> {description}</span>
          </li>
        ))}
      </ul>
    </section>
  ))}
</div>
